# NBA Player Clustering Analysis
An unsupervised machine learning project that groups NBA players into archetype clusters by their distinct play styles using 2025-26 advanced box score metrics and tracking data.

# Project Status
Currently in development

# Project Objective
To discover if unsupervised machine learning can identify modern NBA playing-style archetypes without using traditional position labels. The goal is to find patterns in play style, not player quality. Further goals would be: to apply these clusters to player valuation and determine which players excel the most in these roles, to discover which players have the most statistically similar playing styles, and which combination of player archetypes have winning teams from recent history used in their successful campaigns.

# Planned Workflow
1. Collect NBA data
2. Clean dataset and feature engineering
3. Perform exploratory data analysis
4. Preprocess and dimensionality reduction
5. K-means and Gaussian Mixture Model clustering
6. Interpreting and naming archetype clusters
